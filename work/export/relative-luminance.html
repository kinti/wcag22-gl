Versión MathML da definición de luminancia relativa

A seguinte é unha versión MathML da definición de luminancia relativa das WCAG 2.2. Consulte MathML Software - Browsers para obter información sobre navegadores e complementos compatibles con MathML e que pode necesitar para mostrar correctamente a información desta páxina.

luminancia relativa

o brillo relativo de calquera punto nun espazo de cores, normalizado a 0 para o negro máis escuro e a 1 para o branco máis claro

Nota

Para o espazo de cores sRGB, a luminancia relativa dunha cor defínese como L = 0.2126 × R + 0.7152 × G + 0.0722 × B onde R, G e B se definen como:

  • Se R s R G B ≤ 0.04045 entón R = R s R G B 12.92 en caso contrario R = ( R s R G B + 0.055 1.055 ) 2.4

  • Se G s R G B ≤ 0.04045 entón G = G s R G B 12.92 en caso contrario G = ( G s R G B + 0.055 1.055 ) 2.4

  • Se B s R G B ≤ 0.04045 entón B = B s R G B 12.92 en caso contrario B = ( B s R G B + 0.055 1.055 ) 2.4

e R s R G B , G s R G B , e B s R G B defínense como:

  • R s R G B = R 8 b i t 255
  • G s R G B = G 8 b i t 255
  • B s R G B = B 8 b i t 255

(Fórmula tomada de [SRGB].)

Nota

Antes de maio de 2021 o valor de 0.04045 na definición era diferente (0.03928). Procedía dunha versión máis antiga da especificación e foi actualizado. Non ten efecto práctico ningún nos cálculos no contexto destas pautas.

Nota

Case tódolos sistemas usados hoxe en día para ver contido web asumen codificación sRGB. A menos que se saiba que se vai usar outro espazo de cores para procesar e mostrar o contido, as persoas autoras deberían avaliar usando o espazo de cores sRGB. Se se usan outros espazos de cores, consulte Comprender o Criterio de Éxito 1.4.3.

Nota

Se ocorre tramado (dithering) despois da entrega, úsase o valor de cor da orixe. Para as cores tramadas na orixe, deben usarse os valores medios das cores tramadas (media de R, media de G e media de B).

Nota

Hai ferramentas que fan automaticamente os cálculos ao probar o contraste e o flash.
