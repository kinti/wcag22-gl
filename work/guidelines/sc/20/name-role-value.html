Nome, Función, Valor

A

Para todos os compoñentes da interfaz de usuario (incluíndo, pero non limitado a: elementos de formulario, ligazóns e compoñentes xerados por scripts), o nome e a función poden ser determinados programaticamente; os estados, as propiedades e os valores que poden ser establecidos pola persoa usuaria poden ser establecidos programaticamente; e a notificación dos cambios nestes elementos está dispoñible para os axentes de usuario, incluíndo as tecnoloxías de asistencia.

Este criterio de éxito é principalmente para as persoas autoras web que desenvolven ou programan os seus propios compoñentes da interfaz de usuario. Por exemplo, os controis estándar de HTML xa cumpren este criterio de éxito cando se usan segundo a especificación.
