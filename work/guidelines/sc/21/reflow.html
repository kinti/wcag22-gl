O contido pode presentarse sen perda de información ou funcionalidade, e sen exixir scroll en dúas dimensións para:

  • Contido con scroll vertical a unha anchura equivalente a 320 píxeles CSS;
  • Contido con scroll horizontal a unha altura equivalente a 256 píxeles CSS.

Agás as partes do contido que exixen unha disposición en dúas dimensións para o seu uso ou significado.

320 píxeles CSS equivalen a unha anchura inicial de viewport de 1280 píxeles CSS con zoom ao 400 %. Para o contido web deseñado para facer scroll horizontal (por exemplo, con texto vertical), 256 píxeles CSS equivalen a unha altura inicial de viewport de 1024 píxeles CSS con zoom ao 400 %.

Exemplos de contido que exixe disposición en dúas dimensións son as imaxes necesarias para comprender (como mapas e diagramas), o vídeo, os xogos, as presentacións, as táboas de datos (non as celas individuais) e as interfaces nas que é necesario manter á vista as barras de ferramentas mentres se manipula o contido. É aceptable proporcionar scroll en dúas dimensións para esas partes do contido.
