determinado programaticamente (determinable programaticamente)

determinado por software a partir de datos proporcionados pola persoa autora de xeito que diferentes axentes de usuario, incluíndo as tecnoloxías de asistencia, poidan extraer e presentar esta información ás persoas usuarias en diferentes modalidades

Determinado nunha linguaxe de marcado a partir de elementos e atributos que se acceden directamente pola tecnoloxía de asistencia comunmente dispoñible.

Determinado a partir de estruturas de datos específicas da tecnoloxía nunha linguaxe non de marcado e exposto á tecnoloxía de asistencia vía unha API de accesibilidade que é compatible coa tecnoloxía de asistencia comunmente dispoñible.
