tecnoloxía (contido web)

mecanismo para codificar instrucións que serán renderizadas, reproducidas ou executadas polos axentes de usuario

Tal e como se usan nestas pautas, "tecnoloxía web" e a palabra "tecnoloxía" (cando se usa só) refírense ambas ás tecnoloxías de contido web.

As tecnoloxías de contido web poden incluír linguaxes de marcado, formatos de datos ou linguaxes de programación que as persoas autoras poden usar soas ou en combinación para crear experiencias de usuario final que van desde páxinas web estáticas a presentacións de medios sincronizados e aplicacións web dinámicas.

Algúns exemplos comúns de tecnoloxías de contido web inclúen HTML, CSS, SVG, PNG, PDF, Flash e JavaScript.
