páxina web

un recurso non incrustado obtido dun único URI usando HTTP máis calquera outros recursos que se usen na renderización ou que se pretenda renderizar xunto con el por un axente de usuario

Aínda que calquera "outros recursos" se renderizarían xunto co recurso principal, non necesariamente se renderizarían simultaneamente entre si.

Para os efectos da conformidade con estas pautas, un recurso debe estar "non incrustado" dentro do alcance de conformidade para considerarse unha páxina web.

Un recurso web que inclúe todas as imaxes e medios incrustados.

Un programa de correo web construído con Asynchronous JavaScript and XML (AJAX). O programa vive enteiramente en http://example.com/mail, pero inclúe unha caixa de entrada, unha área de contactos e un calendario. Proporciónanse ligazóns ou botóns que causan que se mostre a caixa de entrada, os contactos ou o calendario, pero non cambian o URI da páxina como un todo.

Un sitio portal personalizable, onde as persoas usuarias poden escoller contido para mostrar dun conxunto de diferentes módulos de contido.

Cando se introduce "http://shopping.example.com/" no navegador, accédese a un ambiente de compras interactivo semellante a un filme onde se move visualmente nunha tenda arrastrando produtos dos estantes ao redor e cara a un carriño de compra visual diante de ti. Ao premer nun produto este demóstrase cunha folla de especificacións flotando ao lado. Isto pode ser un sitio web dunha soa páxina ou só unha páxina dentro dun sitio web.
