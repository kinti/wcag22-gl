píxel CSS

ángulo visual de arredor de 0.0213 graos

Un píxel CSS é a unidade canónica de medida para todas as lonxitudes e medicións en CSS. Esta unidade é independente da densidade e é distinta dos píxeles de hardware reais presentes nunha pantalla. Os axentes de usuario e os sistemas operativos deberían asegurar que un píxel CSS se estabeleza o máis próximo posible ao CSS Values and Units Module Level 3 reference pixel [[css3-values]], que ten en conta as dimensións físicas da pantalla e a distancia de visualización asumida (factores que non poden determinarse polas persoas autoras de contido).
